# Бурбалка — сайт бабл-ти бара (концепт)

Концепт сайта бабл-ти бара в Гродно, сделан для портфолио. «Бурбалка» по-белорусски значит «пузырёк». Маскот — шарик тапиоки Бурба в стиле ризографа: плоские пастельные пятна, зерно и сдвиг розовой краски. Бар вымышленный, маскот и стаканы нарисованы для проекта.

## Что работает
- **Конструктор напитка.** Основа, вкус, до трёх топпингов, сладость, лёд и объём. Ризо-стакан перерисовывается при каждом выборе, цена считается сразу.
- Хиты меню с фильтрами, напиток недели, добавление в корзину одним нажатием.
- Корзина: точка выдачи, время от часов работы (10:00–22:00), проверка имени и телефона.
- Экран «Заказ готовится» с живым статусом и картой лояльности «7 пузырьков»: пузырьки копятся между заказами, седьмой — в подарок.
- Бурба реагирует: машет на первом экране (можно нажать), прыгает в стакан при добавлении, грустит в пустой корзине, спит, когда бар закрыт.
- Адаптивная вёрстка от 375 px, учёт `prefers-reduced-motion`.

Заказы никуда не отправляются, оплата не проводится: это демонстрация интерфейса.

## Технологии
HTML, CSS и JavaScript без фреймворков и сборки. Шрифты Dela Gothic One и Rubik (Google Fonts). Иллюстрации — WebP с прозрачностью.
